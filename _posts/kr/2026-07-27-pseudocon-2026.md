안녕하세요. 바이오인포매틱스 연구자 김가경입니다.

2026년 7월 25일, PseudoCon 2026에서 AutoBioX 팀으로 발표를 마쳤습니다. 가짜연구소 12기 스터디로 4개월간 진행한 두 프로젝트를 처음으로 공개 무대에 올린 날이었습니다.

PseudoCon은 가짜연구소의 연례 컨퍼런스입니다. 올해는 10번째 행사로, 숙명여대 100주년기념관에 약 300명이 모였습니다. 전체 일정이 35분쯤 밀릴 정도로 발표마다 열기가 이어졌습니다.

## 이날의 발표들

도메인이 달라도 발표자들이 수렴하는 지점이 있었습니다. AI가 실행을 처리하고 사람이 판단과 책임을 맡는다는 구분, 그리고 그 경계를 어떻게 설계하느냐는 질문이었습니다. 로봇 연구자, 채용 플랫폼 대표, 바이오 연구자, 에이전트 플랫폼 개발자 — 표현은 제각각이었지만 같은 지점에 서 있었습니다.

**신진수님 (KRAFTON)** 가짜연구소 10번째 컨퍼런스의 문을 열었습니다. AI 시대의 불안을 혼자 감당하기보다 사람들과 만나고 배우며 방향을 찾자는 메시지로 시작했고, "계획된 우연(Planned Happenstance)"이라는 표현이 하루 내내 배경처럼 깔렸습니다. 커리어를 바꾼 기회는 대부분 우연처럼 오지만, 의식적이고 지속적인 과정의 결과라는 논지였습니다.

![신진수(KRAFTON) 오프닝](/assets/images/pseudocon-2026/03_jinsoo_shin.jpg)

**최영준님 (AWS)** GPT-3.5 이후 단발 요청·응답에서 상태를 유지하며 여러 단계를 이어가는 실행으로 AI 패러다임이 바뀌었다는 것이 핵심이었습니다. AWS 내부에서 Amazon Q Desktop으로 슬랙 메시지를 정리하고 아웃룩 메일을 긴급도별로 분류해 쓰는 실사용 사례가 현실감 있었습니다. 에이전트를 팀원으로 보되 권한 범위와 에스컬레이션 규칙을 명확히 정해야 한다는 관점도 짚었고, 프롬프트 수준의 소프트 하네스 외에 "이건 절대 하면 안 돼"라는 정책을 시스템 레벨에서 걸어두는 하드 하네스가 필요하다는 말도 이어졌습니다. "AI가 사람을 대체한다"는 관점 대신 "잘하는 사람의 역량을 더 크게 증폭시킨다"는 말이 이날 가장 오래 남았습니다.

![최영준(AWS) — 행동형 AI: 실행하는 AI의 등장](/assets/images/pseudocon-2026/04_youngjeon_choi.jpg)

**임진하님 (GroupBy HR)** 채용 플랫폼을 운영하며 목격한 변화를 두 가지로 정리했습니다. 기술 스택 체크리스트가 사라지고 있다는 것, 그리고 책임을 지는 일은 AI가 대체할 수 없다는 것이었습니다. 무신사, 카카오페이증권, 채널톡 등이 참여한 해커톤에서는 문제를 아예 안 주고 데이터만 줬는데, 구현 능력이 아니라 "무엇을 구현해야 할지"를 보기 위해서였습니다. AI가 잘못된 답을 내놓으면 죄송합니다로 넘어가지만, 회사에서 잘못된 의사결정으로 손실이 생기면 사람이 책임을 진다는 말이 정말 인상 깊었습니다.

![임진하(GroupBy HR) — AI시대 기업이 원하는 인재상](/assets/images/pseudocon-2026/05_jinha_lim.jpg)

**양유석님 (SK Telecom)** 로봇 AI 모델의 계보를 15분에 압축했습니다. LLM이 텍스트를 처리하는 구조를 피지컬 세계의 시각 인식과 액션 생성으로 확장하는 흐름을 RT1 → VLA → Open VLA 순으로 짚었고, 비전 인코더 병목, Diffusion Policy의 속도 문제, Flow Matching이 denoising 40회를 4회로 줄인 해법까지 공학적 흐름이 명확했습니다. 본인 프로젝트도 솔직하게 공개했습니다. Cosmos를 활용한 데이터 증강으로 MSE 36% 감소했지만 실제 로봇 동작은 아직이라고.

![양유석(SK Telecom) — Physical AI, VLA에서 WAM까지](/assets/images/pseudocon-2026/06_yuseek_yang.jpg)

**Kenny Lee님 (RunPod)** 이날 유일한 영어 세션이었습니다. 지하실 GPU 두 대로 시작해 기존 HPC 대비 90% 비용 절감 사례를 실시간 데모로 보여줬습니다. Pod(가상화 GPU), Cluster(대규모 학습), Serverless Endpoint(프로덕션 배포) 세 계층이 각각 실험, 학습, 배포 용도를 담당하는 구조였습니다. 영업 없이 Reddit 커뮤니티 입소문으로만 성장했다고 했는데, ICML 2026에서 포스텍·KAIST·LG 등 한국 사용자들을 만났다는 이야기도 인상적이었습니다.

![Kenny Lee(Runpod)](/assets/images/pseudocon-2026/07_kenny_lee.jpg)

**공준호님 (SK On)** ChatGPT Work, Codex를 용도별로 나눈 구조를 설명했습니다. GPT 5.6의 Sol·Terra·Luna는 성능 서열이 아니라 작업 맥락에 따라 고르는 다른 역할이라는 정리가 깔끔했습니다. Ultra 모드의 서브 에이전트 병렬 처리, Sites(아이디어에서 배포까지 원스톱), Computer Use 등 최신 업데이트를 실사용 예시와 함께 훑었습니다. "코덱스가 코드를 얼마나 생성했냐"가 아니라 "코덱스와 어떤 결과물까지 완성할 수 있냐"로 기준이 바뀌었다는 마무리가 인상적이었습니다.

![공준호(SK On) — OpenAI Codex Developer Update](/assets/images/pseudocon-2026/08_junho_kong.jpg)

**김수현님 (HDC Labs)** 가짜연구소에 A/B 테스트 플랫폼을 붙이는 과정의 시행착오를 솔직하게 정리했습니다. 처음에 데이터를 먼저 뒤지다가 2~3주를 헤맸고, "데이터를 먼저 보지 말고 목적을 먼저 세워라"는 교훈으로 방향을 바꿨다고 했습니다. PR 머지부터 배포까지 한 달이 걸린 병목, 실험 시작 하루 만에 60시간 데이터 누락 장애가 무대에 올랐습니다. 실험 플랫폼만으로는 부족하고 서비스 연동, 배포, 모니터링, 장애 복구까지 갖춰야 한 사이클이 돈다는 결론이었습니다.

![김수현(HDC Labs) — 가짜연구소를 실험 가능한 커뮤니티로 만들기](/assets/images/pseudocon-2026/09_soohyun_kim.jpg)

저는 2부 세 번째 순서로 "의생명 멀티에이전트 실전기: 단일세포부터 병리 이미지까지"를 발표했습니다. 약 15분, 단독 발표였습니다.

AI 과학자의 현실적 한계에서 이야기를 시작했습니다. 재현율 1.8%, 코드 실패율 40%라는 수치가 이미 보고돼 있습니다. AutoBioX는 이 문제를 멀티에이전트 구조로 풀려 했습니다. 기획, 요약, 예측, 검증, 근거조사 역할을 에이전트별로 나누고, 사람은 최종 판단에만 집중하게 했습니다.

**BioProject01**은 단일세포 크로마틴 멀티오믹스 연구였습니다. 처음 목표했던 chromatin-transcription lag 지표를 계산했더니 상관계수가 0.04였습니다. 사실상 무의미한 결과였습니다. 그런데 분석 과정에서 AI가 새로 제안한 전사 속도(α) 지표는 분석 방법을 바꿔도 Spearman 0.82~0.88로 일관됐습니다. 처음 기대와 다른 곳에서 오히려 더 견고한 신호가 나왔습니다.

**BioProject02**는 유방암 H&E 병리 이미지에서 분자 마커(ER/PR/HER2/PAM50)를 예측하는 연구였습니다. ER·PR은 이미지 기반 예측만으로도 충분하지만, HER2는 추가 분자 검사가 여전히 필요하고, PAM50은 치료 결정이 아닌 예측 목적에 활용해야 한다는 결론이었습니다. 검증 게이트가 닫히기 전에는 수치를 내보내지 않는 원칙을 지켰기 때문에 방법 원칙과 방향 위주로 전달했습니다.

처음 목표한 지표가 실패했다는 것, GPU 서버 물리 장애와 핵심 팀원 이탈, 저장 장치 병목이 실제로 있었다는 것을 슬라이드에 그대로 올렸습니다. 가짜연구소는 다음번에 더 잘하기 위해 지금의 실패를 드러내는 커뮤니티입니다. AutoBioX도 같은 방식을 택했습니다.

**좌민주님 (HF KREW)** Hugging Face 영문 블로그 번역, 품질 검수, SEO, PR 리뷰를 에이전트 루프로 자동화했습니다. 번역 커밋이 생성되면 SEO 스킬과 퀄리티 스킬이 병렬로 돌아가고, 두 스킬의 리포트가 PR 코멘트로 남으면 PR 에이전트가 CI 로그를 읽어 수정 여부를 스스로 결정하는 구조였습니다. GitHub PR 자체를 에이전트 상태 메모리로 쓰는 설계도 인상적이었습니다. "루프 엔지니어링"이라는 개념으로 정리했는데, 프롬프트보다 언제까지 얼마나 돌릴지를 설계하는 것이 에이전트 시스템의 핵심이라는 말이 기억에 남습니다.

![좌민주(HF KREW) — Hugging Face 블로그 에이전트](/assets/images/pseudocon-2026/11_minjoo_jwa.jpg)

**김찬란님 (Pseudo Lab)** 가짜연구소 운영진 대표로 마지막 순서를 맡아 Betoken 개념을 소개했습니다. "토큰이 다음 의미를 예측하듯, 작은 기여와 만남도 성장의 전조가 될 수 있다"는 메시지였습니다. NVIDIA, OpenAI 등 여러 협업이 커뮤니티의 자발적 기여에서 시작됐다는 과정을 공유했는데, 가짜연구소 자체가 그 증거라는 논지였습니다. 12기 빌더들이 오늘 무대에 올린 것도 그 흐름의 일부였다는 말도 덧붙였습니다.

![김찬란(Pseudo Lab) — Betoken: 성장의 전조](/assets/images/pseudocon-2026/12_chanran_kim.jpg)

에이전트 이그나이트에서는 여러 분이 개인 프로젝트를 짧게 선보였습니다. 내가 들은 순서대로 정리합니다.

김민아님(웍스피어)의 **업무 위키 에이전트**는 슬랙, Notion에 흩어진 업무 기록을 구조화해 이력서 초안까지 자동 생성하는 파이프라인이었습니다. 수집과 정제는 됐는데 결과를 믿을 수 있느냐는 다른 문제라는 회고도 솔직했고, "병목은 결국 나 자신"이라는 마무리가 기억에 남았습니다.

![이그나이트: 김민아님(웍스피어) — 업무 wiki로 이력서 업데이트하기](/assets/images/pseudocon-2026/15_ignite_kimina.jpg)

![이그나이트: 박영웅님(SK Telecom) — Personal Knowledge Bases](/assets/images/pseudocon-2026/14_ignite_parkyoungwoong.jpg)

가짜연구소는 AI/ML에 관심 있는 연구자, 개발자, 실무자들이 자발적으로 모여 프로젝트를 진행하는 학습 커뮤니티입니다. 이번 PseudoCon은 그 10번째 컨퍼런스로, 발표 세션 외에 12기 팀들이 진행 중인 프로젝트를 부스로 전시했습니다. 제가 팀원으로 참여한 실험 플랫폼 팀도 4시간 동안 부스를 운영했는데, 발표 준비로 시간대가 맞지 않아 직접 돌지 못한 것이 아쉬웠습니다.

## 뒷풀이

뒷풀이에서는 온라인으로만 연결돼 있던 분들을 처음으로 직접 만났습니다. 다양한 배경의 사람들과 서로 다르면서도 겹치는 이야기를 나눌 수 있어 좋았습니다. 운영진들, 찬란님을 비롯한 여러 분들과 더 많은 이야기를 나누지 못한 건 아쉬움으로 남습니다.

## 다음
